# Proposed KOTOR 1 linking permission

Draft for the copyright owner's approval; not yet part of the project license.

GNU's [GPL and nonfree host program guidance](https://www.gnu.org/licenses/gpl-faq.html#GPLPluginsInNF)
identifies an issue where a GPL plugin and a proprietary host form a combined
program. This plugin calls internal game functions and shares engine structures,
so this is relevant to its intended use. The following narrow GPL section 7
permission addresses only the mod copyright holders' license. It is not publisher
permission and does not resolve the game/store terms discussed in the legal review.

## Proposed text

KOTOR 1 linking permission (GNU GPL version 3, section 7)

The copyright holders who authorize this permission permit you to link or combine
their GPL-3.0-only-covered kotor-coop material with a lawfully obtained copy of the
original Star Wars: Knights of the Old Republic (KOTOR 1) game engine, including
through the mod's plugin interfaces, hooks and internal engine calls, and to convey
the resulting covered kotor-coop material without providing Corresponding Source
for that game engine. All GNU GPL version 3 requirements continue to apply to the
covered kotor-coop material and its modifications, including provision of its
Corresponding Source. This permission grants no rights in the game engine, game
assets or trademarks and does not authorize their redistribution, DRM circumvention
or breach of applicable third-party terms. It grants no exception for other
proprietary libraries or programs. System Libraries remain governed by the GNU GPL
version 3's existing provisions. A contributor may apply this permission to their
contribution by expressly doing so; it does not apply to material whose copyright
holder has not authorized it. Modified versions may retain or remove this
additional permission as allowed by section 7.

## Contribution handling

If approved, publish this permission separately from the unmodified GPL license
text, refer to both from the README and package notice, and explicitly state that
original contributions are submitted under GPLv3 with this permission unless
otherwise identified. Do not apply the permission to third-party dependency code.
