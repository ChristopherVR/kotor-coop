# KOTOR Co-op v0.1 beta

An experimental co-op beta for KOTOR 1 v1.0.3 on Windows, using a lawfully acquired
GOG or Steam copy on each computer. Start with two players and matching game mods.

Extract the Windows zip into a separate folder, close KOTOR and its helper, then
double-click **KotorCoop.Agent.exe**. Setup finds the game, installs and checks the
mod, and preserves existing settings and compatible DLL loaders. One player chooses
**Co-op > Host**; the other chooses **Connect**.

This beta includes the recent dialogue/menu, tutorial Trask, save-input, container
and pause-banner fixes, opt-in settings migration with backups, a double-click log
collector, and full collected dependency notices. Forks for contributing a PR back
to this project are welcome; read LICENSE for independent-release/commercial restrictions.

## Fixes in this beta

- Setup asks whether friends may connect to games you host, and Windows asks for permission.
- Setup notices a game in Program Files and offers to restart as administrator.
- Setup says plainly when no GOG or Steam install is found, when it runs from inside the zip,
  and when `swkotor.exe` is not version 1.03.
- `install --check` says when antivirus has removed `dinput8.dll`.
- Join and compatibility problems appear as plain sentences. The short error tags stay in the logs.
- A joiner whose host stops responding sees a message after about a minute and gives up after
  five minutes, with instructions to reconnect.
- A joiner who connects just after the host starts retries the world fetch instead of failing.
- Your own autosave is kept as "Autosave before co-op" before co-op uses the Auto Save slot, and
  your quick save is restored if the game crashes during a co-op save.
- `swkotor.ini` keeps its original as `swkotor.ini.kcoop-orig`, and uninstall restores it.
- Uninstall removes the mod's extra files and lists what it keeps on purpose.
- `coop.ini` ships with a blank `host =` instead of an example address.
- The agent log rotates during a session instead of growing without limit.

## Beta limitations

- A complete co-op campaign has not been verified. Recent gameplay fixes still
  need ordinary in-game confirmation; back up saves before testing.
- Three-to-eight-player campaign play and all store/network combinations are not
  certified. Internet joining may require firewall/UDP forwarding or a suitable tunnel.
- If the host's helper restarts without restoring the session, host again; process
  restart alone is not session recovery. Unsaved progress can be lost after crashes.
- This is an unofficial mod. It includes no game copy and does not condone piracy.
  Game/store terms, game-media distribution and legal review remain open; publishing
  this beta does not claim legal clearance or change repository visibility.

For a bug report, double-click **KotorCoop.CollectLogs.cmd** on both computers and
include the package version, host/joiner role, game store/mods, reproduction steps
and support zips. Bundles are local; review them for personal information before sharing.
