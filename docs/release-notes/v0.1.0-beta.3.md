# KOTOR Co-op v0.1 beta 3

A fix release for beta 2. Install it the same way, over beta 2: extract the Windows zip into a
separate folder, close KOTOR and its helper, then double-click **KotorCoop.Agent.exe**. Both
players need this same package.

## Fixed in this beta

- **Co-op > Host and Connect did nothing for the first few minutes after the game started.** The
  helper read every game file before it answered the menu. It now remembers what it has
  already checked, and setup does the first check, so Host and Connect answer within seconds.
  Setup spends up to a minute checking your game files the first time.
- While the helper is still starting, the game says so instead of showing nothing.

Everything new in [beta 2](v0.1.0-beta.2.md) is included, and its limitations still apply.
