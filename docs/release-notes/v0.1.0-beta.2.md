# KOTOR Co-op v0.1 beta 2

An experimental co-op beta for KOTOR 1 v1.0.3 on Windows, using a lawfully acquired
GOG or Steam copy on each computer. Start with two players and matching game mods.

Installing is the same as beta 1: extract the Windows zip into a separate folder, close
KOTOR and its helper, then double-click **KotorCoop.Agent.exe**. One player chooses
**Co-op > Host**; the other chooses **Connect**. Both players need this same package.

## New in this beta

- **Duels and the arena** (off unless the host sets `pvp = duel` or `pvp = arena` in
  `coop.ini`). Press F10 to challenge the other player, or type `arena <name>` to fight in a
  ring built from your own game's cantina. The host takes everyone there and back.
- **Shared corpse loot.** An enemy's loot is one copy for the party (`corpse_loot = personal`
  gives each player their own).
- **Story scenes play once, on the host.** Enemies and story characters that a script spawns
  come from the host's game, so the joiner no longer sees duplicates. The joiner follows the
  host's conversations from the first line and leaves them with the host.
- **Cutscenes with both players.** In a scene that moves the player around, your partner stands
  beside you instead of on top of you.
- **Joining a slow host.** The joiner keeps dialing a host that is still loading instead of
  giving up after one try.
- **The Co-op menu button** lines up with the main menu's own buttons at any resolution,
  including with menu mods.

## Fixes in this beta

- The "Item(s) Received" box no longer freezes the joiner after the host reloads, after a
  rejoin or after an arena fight.
- Returning to an area no longer switches its enemies, doors and items off for the joiner.
- A story trigger the joiner walks into spawns its enemies once, in the host's world.
- Companions are not doubled when the joiner walks back into a hideout, and companion
  chatter belongs to the host.
- A joiner's character is saved every few minutes when it changes, so a crash loses minutes,
  not the session. After a host crash the joiner rejoins the host's reloaded world.
- Two host crashes are fixed: one on the Leviathan and one in area pathing.
- The host's public address is only shown when asked for.

## Beta limitations

Everything in the beta 1 limitations still applies: a complete co-op campaign has not been
verified, internet joining may need port forwarding or a tunnel, and unsaved progress can be
lost after a crash. Back up your saves before testing.

For a bug report, double-click **KotorCoop.CollectLogs.cmd** on both computers and include the
package version, host/joiner role, game store/mods, what you did and both support zips.
