PLAYER GUIDE / 01

Install.
Keep your saves.

For KOTOR 1 v1.0.3 on Windows, with a lawful GOG or Steam installation for each player.

No player build has been published in the new release repository yet. These instructions describe the intended installation flow for the reviewed Windows package when it becomes available.

Before installing

  • Back up the game's saves folder to a separate location.
  • Start with two players, the same co-op release and matching game mods.
  • Close KOTOR and any existing co-op agent.
  • Read the release notes and current limitations. KOTOR 2 is not supported.

Install with the setup program

  1. Download kotor-coop-<version>-setup.exe from the latest release (or the same mod from Nexus Mods).
  2. Optional: compare its SHA-256 with SHA256SUMS.txt. In PowerShell, run Get-FileHash -Algorithm SHA256 -LiteralPath 'path-to-the-file'.
  3. Close KOTOR, then run the setup program. It finds your GOG or Steam installation (you can pick the folder yourself) and shows a short options page.
  4. If you intend to host, leave the firewall option on. A game inside Program Files needs administrator approval, which setup asks for once.
  5. Launch KOTOR and press Co-op on the main menu.

No installer? Use the ZIP

Download the Windows ZIP, extract it into its own folder (not over the game), and run KotorCoop.Agent.exe. It does the same job as the setup program.

The installer handles an existing dinput8.dll loader, including compatible loader chaining. It preserves your co-op settings on update. If another mod already uses that file, use the installer instead of manually overwriting it.

Keep antivirus protection enabled. If a file is flagged, stop and report the release version, file hash and detection name for investigation.

What changes

The installer adds the co-op plugin, agent, configuration and supporting files alongside the game. The game executable on disk is unchanged. The mod hooks the running game.

It enables the game's cheat console setting and keeps the original configuration for removal. Co-op uses its own character data and a save named Co-op. Joining uses the game's Auto Save slot, with the previous autosave backed up as Autosave before co-op. Keep your independent backups regardless.

Update or remove

To update, close the game and agent, extract the new release separately, and run its installer. Install the same release on all players' PCs. Existing coop.ini is preserved; review any offered settings migration.

To remove the mod, run KotorCoop.Agent.exe uninstall from the extracted package. Removal keeps your co-op settings, save and character data, and reports what remains. It restores the previous loader/configuration where an installation backup is available.
