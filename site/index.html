01 / THE EXPERIENCE

A familiar world.
A different party.

One player hosts. Friends join as their own characters. The world follows the host; what you bring to it is yours.

01

Travel together.

See each other in the world, move between areas and face the same enemies. Quest progress keeps the party moving in the same direction.

02

Your character. Your gear.

Your backpack and credits stay personal. Quest items are shared so the story can move forward together.

03

One conversation.
Everyone involved.

The player who begins a conversation chooses the replies. The other player can select the same character to watch. Story scenes bring the party together.

04

Pick up where you left off.

Co-op saving and automatic rejoining are implemented. Keep your own save backups: a crash can still cost unsaved progress.

02 / GETTING STARTED

A copy each.
A version in common.

Check your game version, then run the one-click installer.

Installation guide →Host and join →Current limitations →

  1. Own the game.

    Each player needs a lawfully acquired KOTOR 1 v1.0.3 installation on Windows. GOG and Steam are target installations.

  2. Back up your saves.

    Keep a separate copy of your saves before trying the beta. Use matching co-op versions and matching game mods for your first session.

  3. Host. Connect. Play.

    Once installed, use the in-game Co-op menu. One person hosts; the other connects. Follow the release’s installation and network instructions.

A FEW THINGS TO KNOW

Before you return.

Is the original game included?

No. This is an unofficial mod. Every player needs their own lawful game installation; no game executable, keys or DRM bypass are supplied.

Does this replace the single-player game?

The mod loads alongside the game and hooks it while running. Back up saves before using the beta and follow the release’s removal instructions.

Can I use Steam invites?

Steam game support and the optional Steam invite feature are separate. Invites need their own setup and validation; a running Steam client alone does not provide the optional invite library. Direct joining is the baseline.

Can I contribute?

Yes. The mod’s original code is available under GNU GPLv3. Read the contribution guide for build instructions, tests and pull requests. Game assets and separately licensed material retain their own terms.

Where do I report a problem?

Open a GitHub issue with the release version and steps to reproduce it. Review logs before sharing; remove passwords, addresses and personal paths. For security reports, follow SECURITY.md.
