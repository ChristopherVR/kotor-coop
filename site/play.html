PLAYER GUIDE / 02

One hosts.
Friends join.

Start with two players, matching versions and a backup of both players' saves.

A reviewed public player package is still being prepared. Follow the release-specific instructions when that package becomes available.

Your first session

  1. Install the same co-op release on both PCs and launch KOTOR.
  2. The host selects Co-op → Host on the main menu. For a new game, reach the first autosave before starting the shared session.
  3. The other player opens Co-op → Connect and selects the host. For an explicit address, choose Connect to an address….
  4. On a first join, create your own character. That character is kept for later joins.

The host leads world travel and party selection. Keep both the game and its co-op agent running.

On the same network or over the internet

A local host can appear in the server list. If discovery does not work, connect using the host's local address. Confirm that the game versions match and that the host permitted the agent through Windows Firewall.

Internet connections may need port forwarding or a suitable tunnel. There is no built-in relay service, and automatic port opening has not worked reliably on the tested home setup. Share connection information privately; do not post addresses or passwords in public issues.

Steam game compatibility is separate from Steam friends-list invitations. Direct connection is the baseline. Optional invites require additional setup and validation.

How the shared world works

  • Your character and inventory: backpacks and credits are personal by default. Quest items are shared so progression can continue.
  • Conversations: one at a time. Whoever starts chooses the replies. Other players select the same character to watch; story-driven scenes can include both automatically.
  • Party and travel: the host selects companions and leads departures. Let the host handle major recruitment and story decisions during early testing.
  • Combat: players fight shared enemies. Wider player counts and uncommon story fights need more testing.
  • Minigames: one player takes the active seat; the other waits.

Save, leave and return

While connected, use the save named Co-op to return to the session. Keep ordinary named single-player saves separate. Automatic rejoining is implemented, but a crash can lose progress since the last usable checkpoint.

If reconnection stalls, confirm the host has restarted the game and is actively hosting. Check both agents' messages before retrying. Do not assume restarting a helper alone restores the hosted session.

When something goes wrong

Record the release version, GOG/Steam installation, player count, game mods, host/joiner role, what happened and how to reproduce it. Review support logs before sharing; remove addresses, passwords and personal paths. Do not attach game assets or unreviewed support ZIPs.
