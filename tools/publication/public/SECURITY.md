# Security reports

Please use this repository's **Security → Report a vulnerability** option for
confidential security reports. Do not put passwords, private addresses, support
archives, authentication tokens or exploit details into a public issue.

For an antivirus detection, include the release version, archive SHA-256, scanner
name, definition version and detection label. Do not disable protection or add
exclusions to make a detection disappear. A maintainer should investigate and
rebuild or submit a false-positive report as appropriate before publication.

Release scan reports describe a specific package at a specific time. They do not
certify that a package is free from every vulnerability or malicious behavior.
