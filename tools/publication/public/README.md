# KOTOR Co-op

An experimental, unofficial co-op mod for **Star Wars: Knights of the Old Republic**
on Windows. Each player needs a lawfully acquired KOTOR 1 v1.0.3 installation.

**Public release preparation is in progress. No player build has been published
in this repository yet.** This repository contains curated project information,
original promotional media, and future reviewed downloads. Development source,
historical recordings, diagnostic logs and build symbols are kept separately.

## What to expect

- One player hosts; friends join with their own characters.
- Shared travel, combat and story progress, with individual backpacks and credits.
- One conversation at a time; the initiating player chooses replies.
- Co-op saving and rejoining are implemented. Back up saves; unsaved progress can be lost.
- Start with two players and matching mod versions. Wider player counts are experimental.
- A complete co-op campaign remains unverified. Internet play may require forwarding or a tunnel.
- GOG and Steam are target installations. Optional Steam invites need separate validation;
  a running Steam client alone does not supply the optional invite library.

## Downloads and verification

When a reviewed build is available, its release will include the Windows ZIP,
`SHA256SUMS.txt`, and `scan-report.json`. Compare the ZIP's SHA-256 before installing.
The report identifies the exact bytes, antivirus engine, definitions and scan time.
“No detections” is a scan result, not a guarantee of safety or legal clearance.
Do not disable antivirus protection to install the mod; report a detection for investigation.

For ordinary bugs, open an issue with the version and reproduction steps. Inspect
logs before sharing: remove addresses, passwords, personal paths and other private
information. Do not attach game files, saves, executables or unreviewed support archives.
See [SECURITY.md](SECURITY.md) for vulnerability reports.
